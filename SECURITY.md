# Sicherheit

## Lücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue. Nutze stattdessen die private Meldung über GitHub: Reiter **Security → Report a vulnerability** in diesem Repository.

Bitte beschreibe:

- betroffene Version oder Commit
- Schritte zum Nachstellen
- mögliche Auswirkungen

Wir melden uns so schnell wie möglich und halten dich über die Behebung auf dem Laufenden.

## Unterstützte Versionen

Paibot ist in früher Entwicklung. Sicherheitskorrekturen gibt es nur für den aktuellen Stand von `main`.
